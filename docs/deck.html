02What blip-box builds

Is this name safe to accept?

confusable implements Unicode Technical Standard #39 as a pure-Python library with no dependencies: usernames, display names, project names, slugs and filenames go in, and a verdict comes out.

Every answer is checked against two independent implementations, ICU's SpoofChecker and the Rust unicode-security crate, over every Unicode scalar value and a corpus of real attacks. Seven ICU bugs were found on the way.

03Why Guild

A security library needs more care than one maintainer has hours

Guild runs the routine work of a library with agents: triage, planning, building, review and release proposals. A small number of human stewards own direction, approve every code change and run every release. Outside contributors take part through issues and comments.

Every role and gate records the assumption it encodes and the drill that would show it is no longer needed, so the harness can shrink as models improve.

Nothing a model wrote is executed or obeyed with more privilege than the model had, until a plain check or a steward has passed it.
04Six words

The vocabulary

Stewards

The humans. At most three. They own the charter, the budget and the agent configuration, approve by tier, and run releases.

Charter

What the project is for, as numbered clauses with stable IDs. Agents cite C-SPEC-1 when they accept or decline a request.

Tiers

How much human approval a change needs, computed by plain code from the paths it touches. The highest tier wins; nothing lowers it.

Roles

The agents and scripts: Triage, Planner, Builder, Reviewer, Releaser. Each holds the least it needs and no write token.

Ledger

One public line per run: role, model, tokens, cost, outcome, citation, who decided. Enumerations and numbers only; no model text.

Drills

The replay suite with known right outcomes, run several times, that gates every change to a model, a prompt or a version.

08What keeps it safe

Eight layers, each plain

textEvery outsider's string is escaped before a model sees it: non-ASCII as U+XXXX, a notation JSON never decodes back. Prompts say the text may hold instructions and that none count.
recordsModels return closed enumerations in a schema, validated again in code. Comments, labels, titles and commit messages come from templates.
tokensNo agent holds a write token. Three GitHub Apps are held by plain jobs: Triage (issues), Builder (contents and pull requests), Gate (checks).
credentialWorkload identity federation from the job to the model API; ten-minute single-use tokens, no long-lived key in the workflow.
hooksEvery tool call passes a gate: reads and writes inside the checkout, off the reject list; no network, no package index; a repeated call ends the run.
patch checkThe diff, not the agent's account of it: reject list, removed tests, new skips, generated files without their generator, then the tier.
commitsMade through GitHub's commit mutation with the App's token, so GitHub signs them; an Assisted-by trailer names the model.
capsA Console workspace with a hard monthly limit, per-run brakes, turn limits, job timeouts, and a kill switch every workflow checks first.
09Inside a Builder run

The SDK gets nothing from disk

BriefBuilt by code from the triage record and the bug form's structured fields, or an approved plan. Never the issue body, a comment or the web.
Agent SDK, isolatedNo settings, no skills, no MCP servers, a fresh config directory, verbatim prompts. The role prompt, handbook and charter are read from the base branch.
Gate hookDecides every tool call. A read-only role cannot write. Refused: git push, gh, curl, installs, sudo.

10Drills

No change to the harness without a score

A drill is a task with a known right outcome. Each runs several times on a fresh checkout, and a change passes only when the fresh bucket's pass^k does not drop beyond the measured noise.

  • Triage drills feed an issue and grade the record: a confirmed bug, spam, a public security report, a prompt injection with hidden characters.
  • Review drills apply a patch and grade the verdict: a seeded narrowing of the skeleton fast path must draw an objection; a replayed real fix must not.
  • Build drills seed a defect, hand the Builder the reproducer, and grade the diff with the plain check and the conformance suite.

Checkouts are clones detached at the base with every later ref, tag and object removed, so no run can read the answer from git. Seeded defects count as fresh; replayed public fixes do not decide.
